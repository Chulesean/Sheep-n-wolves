 **Poddavki Checkers** - Russian give-away checkers (lose all pieces to win)

 ## Features

- Clean, modular codebase
- AI opponents for both games
- Responsive UI with visual feedback
- Proper game state management
- Asset caching for performance

## How to run

- Run with Visual Studio Code:
   + Open folder "Poddavki" in VS Code
   + Open file "Main.py"
   + Press F5 or click "Run"
- Run with cmd:
  + cd Poddavki
  + python main.py
